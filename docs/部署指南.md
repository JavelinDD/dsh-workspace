# 部署指南（另一台电脑）

本项目**不需要服务器、不需要构建、不需要安装依赖**：取到代码后双击 `apps/pokedex/index.html` 即可使用。
只有需要重新抓取数据或跑自检时，才需要 Node。

## 一、拿到代码

仓库为 **Private**，三种方式任选。

### 方式 A：ZIP 下载（最简单）

1. 登录 GitHub → 打开 https://github.com/JavelinDD/dsh-workspace
2. 绿色 **Code** → **Download ZIP**
3. 解压到任意目录，直接跳到第二节

> 私有仓库必须已登录才能下载；不需要安装 Git。

### 方式 B：SSH 克隆（长期使用，推荐）

新电脑自己生成密钥（不建议直接拷贝旧私钥）：

```bash
ssh-keygen -t ed25519 -C "另一台电脑"
cat ~/.ssh/id_ed25519.pub
```

把公钥贴到 https://github.com/settings/keys → New SSH key，然后：

```bash
ssh -T git@github.com            # 出现 Hi JavelinDD! 即成功
git clone git@github.com:JavelinDD/dsh-workspace.git
```

**中文用户名的坑**：若 Windows 用户名含中文，Git Bash 的 `HOME` 是 GBK 编码，`ssh.exe` 解析不了路径。
克隆完成后补一条（把 `<用户名>` 换成实际值）：

```bash
git config core.sshCommand 'ssh -i "/c/Users/<用户名>/.ssh/id_ed25519" -o IdentitiesOnly=yes -o UserKnownHostsFile="/c/Users/<用户名>/.ssh/known_hosts"'
```

否则 `git push` 会报 `Permission denied (publickey)`。

### 方式 C：HTTPS + PAT

```bash
git clone https://github.com/JavelinDD/dsh-workspace.git
```

用户名填 `JavelinDD`，密码位置填 **Personal Access Token**
（Settings → Developer settings → Fine-grained token，勾选该仓库的 `Contents: Read`）。GitHub 已不接受账号密码。

也可以用 GitHub Desktop 图形化登录克隆。

## 二、使用

### 1. 图鉴（零配置）

双击 `apps/pokedex/index.html`（Chrome / Edge）。372 条数据已内嵌在 `data/pokemon.data.js`，**完全离线**。

### 2. 队伍桥（每台电脑装一次）

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本 → 粘贴 `apps/pokedex/userscript/pokedex-bridge.user.js` 全文 → 保存
3. 打开 https://pokerogue.net → 右下角「图鉴桥」

> 面板底部显示的本地图鉴路径只是提示文字，新电脑路径不同可忽略；图鉴索引已内嵌进脚本，不依赖本地页面。

### 3. 可选：Node 工具

装 Node 20+ 后：

```bash
cd apps/pokedex
node tests/run.js          # 自检 114 项
```

不装 Node 不影响图鉴与队伍桥的使用。

## 三、跨电脑数据同步

浏览器 `localStorage` 不随仓库同步，它存在各自浏览器里。

| 场景 | 做法 |
|---|---|
| 只用内置 372 条 | 无需操作 |
| 原电脑手动改过数据 | 原电脑「导出」→ `pokedex-YYYYMMDD.json` → 新电脑「导入」 |
| 两台电脑长期一致 | 以导出 JSON 为唯一数据源，定期互相覆盖；或直接改 `data/pokemon.data.js` 提交到仓库 |

> 两台电脑各自手改的数据不会自动合并。

## 四、私有仓库注意事项

1. **GitHub Pages 不可用**：免费账户的 Pages 仅支持公开仓库。本项目也不需要托管，双击打开即可。
2. **凭据不能入库**：`.gitignore` 已排除 `conn.json`、`各类网址账号.txt`、`*.exe` 等，提交前照例跑一次 `git status` 自检。
3. **共享电脑要退出登录**：私有仓库的 ZIP 与 Git 凭据都会缓存。

## 六、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `git push` 报 `Permission denied (publickey)` | 新电脑没配 `core.sshCommand`（中文用户名）或公钥未加到 GitHub |
| 双击打开是空白页 | 确认 `data/`、`assets/` 与 `index.html` 的相对位置未被破坏 |
| 队伍桥对手为空 | 不在战斗中；或 `crypto-js` CDN 被拦截（换网络/代理） |
| 导入 JSON 后没变化 | 确认不是隐私模式（localStorage 被禁用），且导入的是本工具导出的格式 |
| 面板打不开 / 数据不刷新 | 确认 Tampermonkey 中脚本版本为最新，刷新页面重试 |

## 七、更新已有部署

```bash
cd dsh-workspace
git pull
```

图鉴与数据内嵌在仓库里，`git pull` 后刷新页面即可；队伍桥若脚本有更新，需要重新粘贴到 Tampermonkey。
