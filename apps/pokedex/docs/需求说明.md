# 需求说明 · PokeDex Lite

## 1. 背景

日常需要查询某只宝可梦的适配信息：特性、被动、推荐性格、推荐配招、出现区域与稀有度、形态与进化关系。
这些信息目前散落在文档、聊天记录与记忆里，无法检索。本工具把它们结构化为可录入、可搜索的本地数据库。

## 2. 目标

- 让「查一只宝可梦」从翻资料变成**输入名字 3 秒出结果**。
- 让「录入一只宝可梦」从散乱文本变成**粘贴模板一键导入**。
- 数据完全本地、可导出、可备份，不依赖网络与账号。

## 3. 范围

### 3.1 做

| 编号 | 功能 | 优先级 |
|---|---|---|
| F1 | 按名称/别名搜索宝可梦 | P0 |
| F2 | 详情展示：特性、被动、推荐性格、推荐配招、区域稀有度、形态、进化 | P0 |
| F3 | 按区域、稀有度、属性筛选 | P0 |
| F4 | 模板文本一键导入 | P0 |
| F5 | 表单新增/编辑/删除 | P1 |
| F6 | localStorage 持久化 + 刷新不丢 | P1 |
| F7 | JSON 导入/导出、恢复种子数据 | P1 |
| F8 | 进化链与区域总览的可视化增强 | P2 |

### 3.2 不做

- 战斗伤害计算、属性克制模拟
- 联网抓取官方图鉴（数据由用户录入）
- 账号、同步、多人协作
- 图片/立绘资源管理

## 4. 数据要求

- 单条记录字段见 [../data/schema.md](../data/schema.md)。
- 稀有度 5 档：普通 / 罕见 / 稀有 / 超级稀有 / 极其稀有。
- 区域 34 类，可配置扩展。
- 每只宝可梦推荐招式 ≤ 10 条，需展示属性、分类、威力、命中、特殊效果及概率。
- 一只宝可梦可出现在多个区域，每区域独立标注稀有度。

## 5. 非功能要求

- **离线可用**：双击 `index.html` 即可运行，不启动服务器。
- **零依赖**：不引入任何 npm 包或 CDN 资源。
- **可维护**：数据与代码分离，数据结构由 `schema.md` 约束。
- **可校验**：`node tests/run.js` 一条命令完成自检。
- **规模**：当前 ≤ 100 只，设计上不设硬上限；数据以 JSON 存储，可平滑扩展。

## 6. 使用场景

**场景 A · 查询**
用户想查「胡帕」适合什么配招 → 打开页面 → 输入「胡帕」→ 看到特性魔术师、被动跟风、性格内敛、5 个推荐招式、出现区域神殿、稀有度超级稀有。

**场景 B · 录入**
用户从别处拿到一段文本 → 点「一键导入」→ 粘贴 → 预览解析结果 → 确认 → 记录入库 → 立即出现在列表。

**场景 C · 备份**
用户点「导出 JSON」→ 得到 `pokedex-YYYYMMDD.json` → 换电脑后点「导入 JSON」恢复全部数据。

## 7. 验收标准

1. 双击 `apps/pokedex/index.html` 能正常打开，无报错。
2. 搜索「胡帕」能命中详情，字段完整。
3. 粘贴模板文本可成功导入，且解析结果可在表单中编辑。
4. 编辑保存后刷新页面，数据不丢失。
5. 导出的 JSON 能重新导入并保持一致。
6. `node apps/pokedex/tests/run.js` 全部通过。
