# 使用手册 · PokeDex Lite

## 1. 打开

双击 `apps/pokedex/index.html`（或右键用 Chrome / Edge 打开）。不需要安装、不需要启动服务器、不需要联网。

## 2. 界面

| 区域 | 作用 |
|---|---|
| 顶栏搜索框 | 输入名称/别名/招式名/特性名即时过滤 |
| 三个筛选下拉 | 按区域、稀有度、属性过滤，可组合使用 |
| 左侧列表 | 点击任一条切换右侧详情 |
| 右侧详情 | 特性、被动、推荐性格、推荐招式表、区域稀有度、进化、备注 |
| 顶栏按钮 | 一键导入 / 新增 / 导出 / 导入 / 恢复种子 |

## 3. 查询

在搜索框输入「胡帕」「Hoopa」「神殿」「戏法空间」都能命中——搜索范围包含名称、别名、形态、特性、被动、性格、招式、区域。

## 4. 新增与编辑

1. 点「新增」打开表单。
2. 基础信息：名称（必填）、形态（默认普通形态）、别名（逗号分隔）、图鉴编号。
3. 属性：勾选 1~2 个。
4. 特性 / 被动 / 性格 / 招式 / 区域：每组下方有「+ 添加」按钮，行尾「×」删除该行。
5. 招式行字段：招式名、属性、分类（物理/特殊/变化）、威力、命中（可填数字或「必中」）、优先度、效果描述。
   - 效果描述里写「20%概率…」，保存时会自动提取概率并显示为标签。
6. 保存后立即出现在列表；编辑入口在详情页右上角「编辑」。

## 5. 一键导入（最常用的录入方式）

点「一键导入」→ 粘贴模板文本 → 点「解析预览」→ 检查预览 → 「确认导入」。

模板格式：

```
胡帕 + 魔术师 + 跟风 + 内敛 + 推荐招式
特性：魔术师 被动：跟风 出现区域：神殿（Temple）
稀有度：非常稀有（Super Rare）/ Boss
性格推荐：内敛（+特攻，-攻击）
推荐招式：
异次元洞：超能力属性特殊招式，威力80，必中，无视守住/替身。
暗影球：幽灵属性特殊招式，威力80，命中100%，有20%概率降低目标特防1级。
```

要点：

- 第一行用 `+` 写「名称 + 特性 + 被动 + 性格」，后面再用标签段精确标注。
- 区域可以写多个，用 `、` 或 `/` 分隔。
- 稀有度支持别名：「非常稀有」会自动归为「超级稀有」。
- 招式以「招式名：」开头，用「。」分隔；最多 10 条。
- 解析结果里的错误必须清零才能导入；提示（如「未包含属性」）不阻塞导入，建议导入后补属性。

## 6. 数据保存在哪

- 默认存在浏览器 **localStorage**（键名 `pokedex-lite-v1`），刷新不丢。
- 关掉浏览器再打开依然在（同一浏览器、同一文件路径）。
- **换电脑、换浏览器、清理浏览器数据都会丢**，所以请定期点「导出」保存 JSON：
  - 导出得到 `pokedex-YYYYMMDD.json`
  - 需要恢复时点「导入」选择该文件
- 「恢复种子」会丢弃所有修改，回到内置的初始数据。

## 7. 常见问题

**Q：打开后是空白/按钮没反应？**
A：确认是用 Chrome/Edge 打开 `index.html`，且 `data/`、`assets/` 目录与该文件保持相对位置。

**Q：提示「当前环境无法使用本地存储」？**
A：浏览器禁用了 localStorage（隐私模式或策略限制）。此时修改只在本次会话有效，请用导出功能手动保存。

**Q：导入 JSON 失败？**
A：文件必须是本工具导出的格式（顶层含 `pokemons` 数组）；普通文本或 Excel 不能直接导入。

**Q：中文名搜索不到？**
A：先用全名（如「胡帕」）试，再检查别名是否录入。

## 8. 自检

在 `apps/pokedex` 目录下执行：

```bash
node tests/run.js
```

若命令行找不到 `node`，用 DSH 自带的：

```bash
"C:\Users\伊谢尔伦\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" tests/run.js
```

全部通过会输出「通过 N 项，失败 0 项 / 全部通过 ✓」。
