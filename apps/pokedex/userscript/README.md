# PokeDex 队伍桥 · 用户脚本

在 [pokerogue.net](https://pokerogue.net) 页面里读取**我方队伍**与**对手**，对照本地图鉴显示属性、稀有度、出现区域与推荐配招。

## 安装

1. 浏览器装 [Tampermonkey](https://www.tampermonkey.net/)（Chrome / Edge / Firefox 均可）
2. 打开 Tampermonkey 面板 → **添加新脚本**
3. 删掉模板，把 [pokedex-bridge.user.js](pokedex-bridge.user.js) 的全部内容粘进去 → **Ctrl+S 保存**
4. 打开 https://pokerogue.net ，右下角出现「图鉴桥」按钮

> 脚本会自动请求 `crypto-js`（CDN）用于解密存档。若你的网络拦截 CDN，对手会降级为不可用，其余功能正常。

## 使用

| 操作 | 说明 |
|---|---|
| 点「图鉴桥」按钮 | 开启/关闭面板，开关状态会记住 |
| 连接状态 | 三行：网站 / 游戏是否加载 / 存档是否可读 |
| 我方队伍 | 名称、等级、HP、属性、特性、被动、性格、招式 |
| 对手 | 同上（来源见下方说明） |
| 稀有度与区域 | 命中图鉴时显示（仅收录稀有及以上 372 只） |
| 刷新 | 立即重新扫描 |
| 复制名单 | 复制「我方：… / 对手：…」文本，可粘贴到别处 |
| 调试信息 | 展开可看捕获方式、数据来源、索引条数 |

## 数据从哪来

| 数据 | 来源 | 说明 |
|---|---|---|
| 我方队伍 | `window.gameInfo` | 游戏**官方暴露、带版本号**的公共接口（`gameInfoVersion: 2.1.0`），含名称/属性/等级/HP/招式/特性/被动/性格 |
| 对手 | `localStorage` 的 `sessionData*` 快照 | 官方存档用常量密钥加密，脚本解密后读 `enemyParty`；物种字段是 `species`（不是实例 ID）。换波/存档后更新，可能滞后一回合 |

> 关于「实时读取对手」：曾尝试用调用栈 `getThis()` 捕获游戏场景实例，但 V8 对 class 方法（严格模式）
> 返回 `undefined`，该方案不可行（已用 Node 复现）。脚本仍保留对 `window.game` / `window.Phaser.GAMES`
> 的低成本探测，命中时才会用实时数据。

## 排除故障

| 现象 | 处理 |
|---|---|
| 右下角没有按钮 | 确认地址是 `pokerogue.net`；Tampermonkey 里脚本是否启用；刷新页面 |
| 显示「等待游戏启动…」 | 正常——点开始游戏后自动出现 |
| 对手为空 | 不在战斗中，或存档尚未更新；进入战斗后点「刷新」 |
| 显示「图鉴未收录」 | 该宝可梦不在 372 只稀有+ 数据集里；游戏原始属性仍会显示 |
| 对手名称显示「物种 #数字」 | 该物种的 `species` 超出基础图鉴号范围（形态 ID），或未被收录；可用调试区的 `enemyFields` 排查 |
| 对手来源一直是「存档快照」 | 属正常路径：实时读取在发行版不可行（见上） |
| `crypto-js` 加载失败 | 换网络/代理，或把 CDN 地址改为可访问的镜像 |

## 安全边界

- **只读**：不写存档、不改游戏状态、不自动操作。
- 只在 `pokerogue.net` 域运行，不向任何服务器发送数据（唯一外部请求是 CDN 拉取 crypto-js）。
- 游戏更新可能让「实时对手」失效，脚本会自动降级到存档快照，不会报错刷屏。

## 重新生成

图鉴数据更新后重新生成脚本：

```bash
cd apps/pokedex
node tools/build-userscript.mjs
```

然后把新生成的 `pokedex-bridge.user.js` 重新粘贴进 Tampermonkey（或直接打开该文件，Tampermonkey 会提示安装更新）。
